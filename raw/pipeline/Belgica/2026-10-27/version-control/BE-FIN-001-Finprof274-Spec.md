|  | LANGUAGE OF COLUMN B — POSITION AND OUTSTANDING DELIVERABLE | CCG Module 1.1 does **not** document a single national default language. It imposes the language of a personnel document by the region of the employer's seat of operation — Dutch in Flanders, French in Wallonia, German in Ostbelgien, the employee's language in Brussels — and states that bilingual personnel documents are not permitted in Belgium. Column B of this specification carries the **official Dutch** field name exactly as published in the source, which is itself the Dutch-language edition. |  | A MISLABELLED SOURCE FILE — DO NOT USE IT FOR THIS RETURN | 00-official-sources/spec-sources/FPS-Finance_BV_codenummers_aard_inkomsten.pdf is named as though it carried the bedrijfsvoorheffing income-nature codes. It does not. Its content is the code-number table for **roerende voorheffing** — withholding tax on movable income, form 273 — with codes 11, 21, 22, 23, 24, 31, 41, 51 and so on at rates of 25%, 15% and 12.50%. Those codes have NOTHING to do with the wage withholding tax and must never be mapped into RevenuNature. The authentic RevenuNature list is in the SS274EUR-XML file description itself and is reproduced in full in the Field Options sheet of this workbook. |  |  |  |
