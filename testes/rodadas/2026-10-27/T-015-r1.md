## Resposta

**Host (régime général):** depot.dpae-edi.urssaf.fr, the URSSAF DPAE filing point. Deposits go to https://depot.dpae-edi.urssaf.fr/deposer-dsn/1.0/. Before that, the software gets a token from https://mon.urssaf.fr/authentifier_dpae. Returns (AEE, certificate of conformity, AR) come back through consultation.dpae-edi.urssaf.fr and telechargement.dpae-edi.urssaf.fr.

**Accepted formats:** the request accepts the DPAE XML format and the flat-file ("à plat") DPAE format, but not archives. Both follow format 120 for the DPAE and the acknowledgment (TXT or XML). A flow must be a single file with a size greater than zero, and the maximum size for an API deposit is 100 MB.

**Sources:**
- URSSAF, *Guide d'implémentation de l'API DPAE* (NAT/5492), section "Service de dépôt d'une DPAE – Requête": https://www.urssaf.fr/files/live/sites/urssaffr/files/outils-documentation/guides/Guide-API-DPAE-Impl.pdf
- URSSAF, *L'API DPAE – Questions/Réponses*, under "Quel est le scénario de base d'un dépôt de Dpae en API ?": https://www.urssaf.fr/files/live/sites/urssaffr/files/autres/API-DPAE-FAQ.pdf
- URSSAF, *API DPAE RG – Principes de fonctionnement* (NAT/6804, Sept 2025), under "Format du fichier": https://www.urssaf.fr/files/live/sites/urssaffr/files/outils-documentation/guides/API-DPAE-Fonctionnement.pdf

The URSSAF site blocks automated fetching, so I took the quoted text above from search extracts of these PDFs and did not open them in full. Please confirm the section headings when you open them.

**Timing note:** a DPAE signal inside the DSN (nature 10) is specified in the 2026 DSN technical spec, but a secondary source reports its go-live has been postponed to 1 January 2027. The channels above still apply in the meantime.
