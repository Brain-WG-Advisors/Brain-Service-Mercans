## Payroll Scope Summary

| US-IRS-001 FORM 941 EMPLOYER'S QUARTERLY FEDERAL TAX RETURN — PAYROLL SCOPE SUMMARY |  |  |
|---|---|---|
| Who and what the quarterly federal employment tax return carries, built from the payroll results of the wages paid in the quarter. |  |  |
| SCENARIO | REPORT? | NOTES / REASONING |
| ═══ WHO GETS REPORTED ═══ |  |  |
| Common-law employees of a private-sector employer paid in the quarter | YES | Every employee with wages paid in the quarter enters the amounts of the return [US-OWN-008]. |
| Statutory employees (federal layer) | YES | Included at the federal layer; FICA applies, FIT per the CCG rules [US-OWN-005, US-FEDR3-005]. |
| Independent contractors (Form 1099-NEC) | NO | Out of scope by owner instruction [US-OWN-008]. |
| Household employees | NO | Reported by the household employer on Schedule H (US-IRS-005) [US-FEDS5-029]. |
| Agricultural employees | NO | Reported on Form 943 (US-IRS-003): calendar quarter (Form 941); agricultural labor annual; Form 944 annual option. |
| ═══ TIMING & RELATIONSHIP ═══ |  |  |
| Quarterly return | YES | quarterly; due last day of month after quarter; amounts in cents [US-FEDS5-004]. |
| Employer notified to file Form 944 instead | NO | An employer notified in writing files Form 944 (US-IRS-002): annual, only on written IRS notice, liability of 1,000 or less. |
| Corrections of a filed quarter | NO | Filed on Form 941-X (US-IRS-008), never on a later Form 941. |
| Reconciliation with Forms W-2/W-3 | YES | The four quarters must reconcile with the W-2/W-3 totals of the year (US-SSA-001) [US-FEDS5-031]. |
| ═══ AMOUNTS & CALCULATIONS ═══ |  |  |
| Social security wages capped per employee | YES | Annual base 184,500; lesser of remaining base and period wages. |
| Additional Medicare above the threshold | YES | Employee-only 0.9% above 200,000. |
| Amounts in cents | YES | quarterly; due last day of month after quarter; amounts in cents. |
| ═══ SPECIAL CASES ═══ |  |  |
| Nonresident aliens in F, J, M or Q status | PARTIAL | FIT wages reported; FICA amounts exclude exempt pay. |
| Employees under a totalization agreement | PARTIAL | FICA amounts exclude covered wages [US-FEDR2-003]. |
| Multistate employees | YES | Form 941 is federal; State amounts go to the State returns (US-DOR-001). |
| US citizens or residents working abroad | YES | Included at the federal layer under the CCG rules [US-OWN-005, US-FEDR3-007]. |
