Web service

The web service is intended for the submission of documents completed by an accounting program or other software;

How to start?

  • After logging in to EDS, in the "Settings" → "My data" section, select that you will use a web service and create a username and password for data transfer (for legal persons only).
  • If you want to submit documents using a web service, the accounting program or other software you use must meet the requirements of the document service specification (web service). Manufacturers or distributors of your accounting software should prepare them for use with this service.

How to submit?

  • Submit the declaration data using the web service and the created username and password.
  • Sign into the EDS within 3 days of sending the declaration and confirm the submission of the declaration submitted using the web service in the section "Declaration" → "Confirm the completed form". Declarations may be validated by any external user entitled to submit a validated declaration. If the declaration submitted within 3 days is not approved, it will be deleted from the system and the submission of the declaration will not be counted.

You can also check the status of files or declarations submitted via the web service using the web service. The results of the audit may be provided in your accounting software, provided that the accounting software or other software you use is prepared for use by the web service and meets the requirements of the service specification.
