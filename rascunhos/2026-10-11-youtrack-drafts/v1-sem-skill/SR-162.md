Checked against the official XSD **J0510510 v10** (ДПС package, наказ Мінфіну № 39/2025) and the form itself.

**1. Rows 55–56 (HDDGV / HNDGV):** correct, no mapping needed. Both are optional and nillable (HDDGV = date DDMMYYYY, length 8; HNDGV = free text, no length). In the XML they must be **omitted** (or sent with `xsi:nil="true"`), never as empty tags.

**2. Rows 37–51 ("Blank"):** not correct for all of them. Per the XSD:
- **Row 43 Region Code (C_REG)**, **row 44 District Code (C_RAJ)** and **row 48 Tax Authority Code (C_STI_ORIG)** are **mandatory** (C_REG/C_RAJ integer 0–99; C_STI_ORIG = ДПС office code, 3–4 digits). They need to be mapped from the legal entity (region, district and code of the ДПС office where the employer is registered) — this is why the sample shows `<C_REG>26</C_REG>`.
- **Row 50 Form Fill Date (D_FILL)** must be **DDMMYYYY, length 8, no separators** (the spec currently says DD-MM-YYYY / 10).
- **Row 49 LINKED_DOCS** and **row 51 SOFTWARE** are optional: Blank is fine (omit the tags).
- Rows 37–42, 45–47: OK as mapped.

**3. Other spec rows to align with the form:**
- **Rows 53–54 (HBOS / HBUH)** are not signatures: they are the **first name and SURNAME** of the director (HBOS, mandatory) and of the chief accountant (HBUH, optional). The KEP signature is applied to the file, not to these tags.
- **Row 30 ("Graf 19")** = column 19 of the form, **"Військове звання"** (military rank).

**4. Testing feedback for @mjohn** — the acceptance sample (24-07-2026) fails XSD validation:
1. C_REG, C_RAJ, C_STI_ORIG empty (mandatory).
2. `<LINKED_DOCS />` empty — omit it (if present it requires `DOC`).
3. All dates must be **DDMMYYYY** without separators (D_FILL, HFILL, T1RXXXXG101D, G102D, G18D).
4. **HZ / HZN / HZU is an exclusive choice**: only one of the three tags, with value `1` (no leading space). The template currently outputs all three.
5. HDDGV / HNDGV: omit instead of `<HDDGV nillable="true" />`.
6. **Table order:** the XSD expects the rows **by column** — all `T1RXXXXG5` (ROWNUM 1..n), then all `T1RXXXXG6`, and so on. The template writes G5…G20 per employee, so any file with 2+ employees is rejected.
7. Empty columns (e.g. G19S, G20) must be omitted, not sent empty.
8. HBOS (director's name) and HKBOS are mandatory.
