## Payroll Scope Summary

| US-IRS-002 FORM 944 EMPLOYER'S ANNUAL FEDERAL TAX RETURN — PAYROLL SCOPE SUMMARY |  |  |
|---|---|---|
| Employers notified by the IRS to file one annual return instead of four quarterly returns. |  |  |
| SCENARIO | REPORT? | NOTES / REASONING |
| ═══ WHO GETS REPORTED ═══ |  |  |
| Employers notified in writing by the IRS | YES | annual, only on written IRS notice, liability of 1,000 or less |
| Employers without the notice | NO | They file Form 941 (US-IRS-001). |
| ═══ TIMING & RELATIONSHIP ═══ |  |  |
| Annual return | YES | One return per calendar year; For 2026: file Form 944 by 2027-02-01; by February 10, 2027 if all deposits were made on time in full. |
| Quarterly Form 941 for the same year | NO | Never both for the same year. |
| ═══ AMOUNTS & CALCULATIONS ═══ |  |  |
| Same amount definitions as Form 941 | YES | Rows F944-005 to F944-009. |
| ═══ SPECIAL CASES ═══ |  |  |
| Household and agricultural employees | NO | Schedule H (US-IRS-005) and Form 943 (US-IRS-003). |
