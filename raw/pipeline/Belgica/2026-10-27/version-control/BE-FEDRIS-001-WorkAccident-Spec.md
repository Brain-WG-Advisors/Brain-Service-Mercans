|  | LANGUAGE OF COLUMN B — POSITION AND OUTSTANDING DELIVERABLE | CCG Module 1.1 does **not** document a single national default language. It imposes the language of a personnel document by the region of the employer's seat of operation — Dutch in Flanders, French in Wallonia, German in Ostbelgien, the employee's language in Brussels — and states that bilingual personnel documents are not permitted in Belgium. Column B of this specification carries the **official French** field name exactly as published in the NSSO glossary edition held in 00-official-sources (edition 2026/2, FR). The NSSO publishes the same glossary in Dutch; the Dutch labels were NOT machine-translated from the French, because these are official field identifiers and a translated label is an invented label. The remaining official-language editions are a mandatory further deliverable and are NOT built here. This is the same documented gap BE-WTC-001-v1.1 carries in its own Version Control remark on the local-language column. |  |  |  |

|  | WHY THIS IS SEPARATE FROM BE-NSSO-004 EVEN THOUGH IT IS THE SAME FAMILY | Technically the work accident declaration is a DRS scenario like any other: the same envelope, the same zone numbering, the same channel, the application code AOAT alongside WECH, ZIMA and TWCT. It is specified separately because BE-SIR-001 registers it as its own outbound integration — OUT-07, distinct from OUT-06 — with a different destination (the employer's insurer and Fedris, rather than the NSSO and the paying institutions), a different statutory deadline (8 days, fixed, rather than 'on the triggering event'), and a different mapping requirement. Treating it as a section of the DRS specification would hide a filing with its own legal deadline. |  |  |  |
|  | THE LARGEST NON-PAYROLL DATA REQUIREMENT IN THE BELGIAN SET | Of the 38 functional blocks in this scenario, roughly half carry data that does not exist in a payroll system at all: the circumstances of the accident, its location, the protective equipment in use, the prevention measures, the medical consequences, the treating doctor, the hospital, any witness, any liable third party, and any official police report. Payroll supplies the victim's identity, the employment and working-time position and the reference wage; everything else must be captured from the client through an intake process. A build that treats this as a payroll extract will produce a declaration the insurer cannot act on. |  |  |  |
|  | FEDRIS CONTRIBUTIONS ARE A DIFFERENT OBLIGATION | The DmfA carries Fedris contributions through its own worker codes (BE-NSSO-002 zone 00082, contribution worker codes representing a Fedris contribution, with cardinality 1 or 2 on block 90001). That is the financing of the occupational disease and work accident system and it is quarterly. THIS declaration is the notification of an individual accident and it is per event. The two must not be conflated. |  |  |  |
