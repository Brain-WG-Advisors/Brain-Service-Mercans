## Result of the self-check (re-run 2026-11-03 against a text cache rebuilt from the register)
- Official `selfcheck.py`: 22 misses in total; **8 in this share** (6 keys), down from 85.
- Patched copy (scratch only, the shared tool was not edited): **4 in this share** (2 keys).
- Each of the residuals was found by hand in the cited copy. None comes from a source gap:
  1. **Tool defect, number words.** In `selfcheck.py` the number-word regex is built from the string literal `'\b'` (not raw), which Python reads as a backspace (0x08). "twenty" can therefore never match. This affects `az.newhire.report_days` and `la.newhire.report_days` (=20; "within twenty days" / "no later than twenty days"). The fix is to write `r'\b'`. The same defect hides `ne.`/`oh.newhire.report_days` in share B.
  2. **Tool limit, percent stored as a fraction.** `fed.futa.credit_reduction.ca/vi.potential.rate` (5.3 / 4.8 percent): the DOL xlsx stores 0.053 / 0.048 with number_format `0.0%`. `numv_find` tries v and v*100, not v/100. Adding `v/100` clears both.
  3. **Text layer joins tokens.** In `rspec.la.wh_return.form`, Apr 30 / Jul 31 / Oct 31 are in US-LAS5-008 LAC 61:I.1501.B, p1, but the PDF text layer reads "first quarterApril 30", with no word boundary, so the date regex `\bapril` fails. A date pattern without the leading `\b` would match. The value was **not** rewritten to dodge the regex.
  4. **Count of a table.** `rspec.fed.w2.box14b.ttoc_count` = 71 is a count of the TTOC table rows: 71 distinct codes parsed (10+11+4+9+10+11+6+10). The page prints no total. The verification is "inspected directly"; no text match is possible.

**Priority suspect `rspec.la.wh_return.form`: confirmed defect, fixed.** The cited LDR Withholding page (US-LAS5-003) carries the L-1, LaTAP, the zero-return rule and the annual January 31 date, but **no quarterly due dates**. The dates were re-pointed to US-LAS5-008, LAC 61:I.1501.B ("1. first quarter April 30; 2. second quarter July 31; 3. third quarter October 31; 4. fourth quarter January 31"), and the value now names the instrument. Caveat in the quote: 1501.B is worded as *payment* due dates, and the L-1 return goes with the quarterly payment (1515.A). `rspec.la.annual_recon.form` was also re-pointed to US-LAS5-008: the W-2s and "first business day following January 31" come from 1515.B, not from the page.
