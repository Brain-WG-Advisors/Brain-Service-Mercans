# T-003
**Question:** Spain, Modelo 190: which perception key (clave/subclave) for WT 79432 Parental Leave Payout, WT 79429 Breastfeeding Risk Payout and WT 79430 Pregnancy Risk Payout?

**Answer:**
- **79432 → Clave L, subclave 27** ("Prestaciones públicas por maternidad o paternidad exentas del IRPF"). Confirmed.
- **79429 / 79430 → not confirmed.**
  - WTC V4.7 still maps both to Clave B / subclave 03.
  - In the 190 design for exercise 2025 onwards (Orden HAC/1431/2025), subclave B.03 = "Prestaciones percibidas por los beneficiarios de mutualidades generales obligatorias de funcionarios, colegios de huérfanos y entidades similares". It no longer fits these benefits.
  - The design has no explicit key for risk during pregnancy/lactation. Possible candidates:
    - B.01, if read as incapacity-type benefits paid directly by INSS/Mutua.
    - B.99, the residual.
    - Clave A, if the employer pays.
  - Confirm with the AEAT before answering. Do not use B.03 for exercise 2025 onwards.
