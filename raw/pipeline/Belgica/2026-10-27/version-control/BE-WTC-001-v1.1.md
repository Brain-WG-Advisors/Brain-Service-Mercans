|  | LANGUAGE OF THE LOCAL-LANGUAGE COLUMN - DUTCH, WITH FRENCH OUTSTANDING | Belgium has no single national payroll language. Under CCG Module 1.1 the language of every personnel document is imposed by law according to the EMPLOYER'S SEAT OF OPERATION, not the employee's residence: Dutch in the Dutch-language region (Decree of 19 July 1973, sanction NULLITY), French in the French-language region (Decree of 30 June 1982, sanction nullity), the language of the EMPLOYEE in bilingual Brussels-Capital (coordinated laws of 18 July 1966, sanction translation at the employer's expense with retroactive effect), and German in the German-language region. There are NO bilingual personnel documents in Belgium, not even in Brussels: each payslip is unilingual, and an English payslip is never sufficient on its own. DOCUMENTED DEFAULT FOR THIS VERSION: column C is populated in DUTCH as the first-built language. A FRENCH-LANGUAGE VERSION OF COLUMN C IS A MANDATORY SECOND DELIVERABLE AND IS NOT YET BUILT; a German version is required only for employers seated in the German-language region. Do not deploy this catalogue for a Wallonia-seated or Brussels employer until the French column exists. |  |  |  |
|  | SOCIAL SECURITY STRUCTURE - SINGLE FUND, NO PER-FUND COLUMN EXPANSION | Belgian employee social security is ONE global contribution of 13.07% of gross with NO CEILING (globaal beheer), collected by the NSSO and allocated to the branches administratively - pensions 7.50%, medical care 3.55%, sickness and disability 1.15%, unemployment 0.87%. Payroll does NOT configure per-branch subject-to flags. Columns Q (Subject to Social Insurance) and R (Subject to Pension) are therefore used EXACTLY as the CZ template defines them and have NOT been expanded into per-fund columns. Because the first-pillar pension is a branch INSIDE the single global contribution and there is no separate pension deduction in Belgium, column R mirrors column Q wherever the global contribution applies. |  |  |  |
