# T-022

**Pergunta:** Gabon WTC: which Global WTC code ranges must the Gabon Wage Type Catalogue contain for employee deductions and for employer contributions?

**Resposta:**
Employee deductions: Global WTC block 21100-21900. Employer contributions: block 23640-23673. Both were missing from GA WTC v3.0 (59 codes) and were added in GA WTC v3.1 DRAFT (2026-09-23, HRBS-14978). Open point: platform code numbers of the new v3.1 codes still to be confirmed.
