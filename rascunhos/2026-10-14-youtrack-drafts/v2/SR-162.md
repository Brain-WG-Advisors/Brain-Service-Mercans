1. Row 49 (LINKED_DOCS) is filled for D5. D5 is an appendix to the Tax Calculation J05 001 (section 06, row 065), and a reporting package contains the main document and its appendices. For an appendix, LINKED_DOCS contains the reference to the main document: one DOC, TYPE="2", whose elements repeat the main document's header: C_DOC = J05, C_DOC_SUB = 001, C_DOC_VER = 11, C_DOC_TYPE, C_DOC_CNT and C_DOC_STAN of the main document, and FILENAME = the main document's XML file name. Spec v3.3: row 49 and the XML sample updated (light blue).
Row 51 (SOFTWARE) is the one sent as `<SOFTWARE xsi:nil="true"/>` when empty.
Is the main Tax Calculation (J05 001) generated by the system? There is no spec for it, and the LINKED_DOCS values come from that file.

2. HFIL (row 10) is filled only in an "Уточнюючий" calculation that corrects data of a branch (including a closed one); otherwise it is omitted.

Source: наказ Міндоходів № 729/2013, Додаток 1 (items 3–4, LINKED_DOCS); form J05 001, section 06; form D5 (J0510511), note 7.
