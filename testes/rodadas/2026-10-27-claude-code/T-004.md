# T-004
**Question:** Spain, SEPE Certific@ XML: the DD stores the occupation as the 4-digit CNO code (T90), e.g. 3123. How must CodProfesion be populated?

**Answer:**
Right-pad the 4-digit CNO code with zeros up to 7 digits: 3123 → **3123000**.
- The DD stays at 4 digits (CNO-11 / table T90). The padding is applied only in the report mapping.
- Fixed in CERTIFICA spec v1.1 (row 30).
- Open point: acceptance on the SEPE portal is not yet confirmed (hub pendência, HRBS-13757).
