# T-015-r2

- **Pergunta:** France: when payroll software transmits the DPAE (déclaration préalable à l'embauche) electronically, which host receives it and in which file formats can it be sent?
- **Data/hora:** 2026-10-27 10:26
- **Modelo:** Opus 5.5 (esforço Alto), claude.ai, chat novo fora de projeto, sem anexos
- **Configuração:** conectores desligados no chat; skills Mercans ativas; busca na web, memória e pesquisa em conversas anteriores ativas (padrão da conta)
- **Chat:** https://claude.ai/chat/eeefafed-7e06-45d7-8d54-3e07a95d32e4

## Resposta

Payroll software sends the DPAE to the URSSAF host **depot.dpae-edi.urssaf.fr**. The full deposit endpoint is `POST /deposer-dsn/1.0/`. Concentrators must specify port 8443 in the deposit service URL. Before depositing, the software has to get a token from https://mon.urssaf.fr/authentifier_dpae. Returns are then fetched from consultation.dpae-edi.urssaf.fr and telechargement.dpae-edi.urssaf.fr.

Both formats are accepted: DPAE XML and DPAE "à plat" (flat file). The flat file is the DPAE format 120, which applies to both the DPAE and its acknowledgment (TXT or XML).

**Source:** URSSAF, *Guide d'implémentation de l'API DPAE*, in the "Adresse des services" table and the deposit request example: https://www.urssaf.fr/files/live/sites/urssaffr/files/outils-documentation/guides/Guide-API-DPAE-Impl.pdf

This covers the general regime only. Agricultural employers file with the MSA through a separate channel.
