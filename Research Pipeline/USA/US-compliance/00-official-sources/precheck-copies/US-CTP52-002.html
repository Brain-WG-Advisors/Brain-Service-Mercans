Information for Third-Party Agents (TPAs)

Who Qualifies as a Third-Party Agent (TPA) in ReEmployCT?

Any entity that files and/or pays unemployment taxes on behalf of another employer, whether related or not, should register as a TPA. This can include, but is not limited to:

  • Local, regional, and national payroll agencies,
  • CPAs and/or bookkeepers,
  • Professional Employer Organizations (PEO),
  • Corporate payroll departments filing for subsidiaries.
  • Frequently Asked Questions
 

Certificate of Representation (COR) 

TPAs are required to complete a Certificate of Representation (COR).

Required Form to Link Employers to Tax Filing TPA 

A TPA who needs to file an amendment return or perform account maintenance for their client(s) would need to link their client's accounts to the TPA. This access is granted by completing this form.
Please send the completed COR and/or linking spreadsheet to dol.status@ct.gov for processing. Note: Your client(s) do not have to be linked to your TPA account to file bulk tax and wage returns and/or make ACH credit payments.

File Formats

Bulk Filing Formats:
  • There will be no file size limitation for the wage or payment file in the new system. 
  • There will be no limit to how many files you can upload per day. If you want to replace a file, confirmation number should be entered. Additional reports can be added to already uploaded file but if you choose not to then previous unprocessed file submitted will be replaced with the current file being uploaded.
  • The UI File name is not required in the new system, but there will be a 276-character limit. The file name must
    have a .txt extension.

Bulk File Format Requirements 

ReEmployCT New Format Overview. ReEmployCT will allow employers to securely login to the ReEmployCT system and directly upload their files for processing; they will no longer use the File Transfer Protocol (FTP).
