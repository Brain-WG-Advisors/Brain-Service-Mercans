Apie formų teikimą

Dokumentus galima pateikti:

  • Užpildant ir pateikiant dokumentą tiesiogiai EDS portale;
  • Užpildytas formas  persiunčiant per EDS portalą;
  • Perduodant duomenis naudojantis žiniatinklio paslauga („web service“).

Apie deklaracijos priėmimą EDS ir jos apdorojimo rezultatus galima sužinot:

  • prisijungus prie EDS ir skyrelyje „Pateikti dokumentai ir formos“ patikrinti deklaracijos priėmimo EDS faktą;
  • papildomai mokesčių mokėtojas gali būti informuojamas jo nurodytu elektroniniu paštu, jeigu informavimo elektroniniu paštu nustatymus yra pasirinkęs.

Dėmesio! Per Elektroninio deklaravimo sistemą galima teikti saugiu elektroniniu parašu pasirašytus dokumentus pagal Lietuvos Respublikos elektroninio parašo įstatymo nuostatas. Mokesčių mokėtojai, norėdami teikti elektroniniu parašu pasirašytus dokumentus, turi iš naujo sudaryti Dokumentų teikimo elektroniniu būdu sutartis, sudarytas iki 2010 m. liepos mėn. 29 d.

Reikalavimai interneto naršyklei:

  • HTML vesijos 4.1 palaikymas;
  • SSL v3. šifruoto HTTP kanalo palaikymas;
  • JavaScript modulių palaikymas naudotojo kompiuteryje pagal Microsoft JavaScript standartą (Internet options -> Java (sun) – nurodytas naudojimas);
  • Failų persiuntimo išsiuntimo / atsisiuntimo palaikymas (upload/download);
  • HTML rėmelių (frames) palaikymas;
  • Darbo seanso identifikatorių palaikymas (session cookies).

Rekomenduojama naudotis šiomis interneto naršyklėmis ir ne senesnėmis, nei nurodyta, jų versijomis:
Microsoft Internet Explorer 6.x, Opera 9.x, Mozilla FireFox 2.x , Apple Safari (MAC vartotojams)

Dėmesio! Rekomenduojama, kad naršyklės nustatymai būtų standartiniai (default), taikomi diegiant naršyklę. Esant tam tikriems naršyklės saugumo (security) nustatymams, Java naudojimo apribojimams kai kurios EDS funkcijos, gali neveikti. .
