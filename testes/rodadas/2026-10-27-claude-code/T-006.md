# T-006
**Question:** Spain WTC: should WT 65815 be mapped to Modelo 296? What is its current classification?

**Answer:**
No. In WTC V4.7, 65815 has no 296 mapping: AEAT 296 Key/Subkey are blank. Current classification:
- Name: "Flexible Remuneration - Non-Taxable SS Subject"
- Category Benefit, Payment Type Kind, Flex Rem salary-sacrifice benefit
- Subject to Tax = No; BCCC/BCCP = Yes; CRA code 39
- AEAT 190 Clave L / L24, Exempt_InfoOnly, not in 111, not subject to 216
- Basis: Art. 42.3 LIRPF exemption; SS-subject under art. 109 LGSS
