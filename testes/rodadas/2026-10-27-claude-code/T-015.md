# T-015

**Pergunta:** France: when payroll software transmits the DPAE (déclaration préalable à l'embauche) electronically, which host receives it and in which file formats can it be sent?

**Resposta:**
**Host:** URSSAF's own DPAE host (the DUE/DPAE service at `www2.due.urssaf.fr`, via the DPAE API/EDI). It does not go to net-entreprises. The earlier manifest ("via net-entreprises, XML only") was wrong.

**Formats** (either one):
- the flat text "format 120" (TXT): a fixed-length record of 989 characters + LF = 990 bytes, ISO-8859-1, 24 fields, record layout v5.4;
- XML (FR_DUE_Upload variant).

Without software, the employer can fill in the form on the URSSAF portal instead.

Caveat: the 990-byte record length is UNVERIFIED in FR-TEST0 R09, because the host did not respond on 2026-10-09. The URSSAF DPAE API guide confirms only that the flat and XML formats both exist.
