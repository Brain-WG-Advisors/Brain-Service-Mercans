The PGL1 notice has no Plan Type. In HMRC's DPS schema for PGL1 (PostgraduateLoanStart-v1-0.xsd, outgoing schemas v2.93) the only loan field is LoanStartDate, next to EmployerRef, NINO, Name and WorksNumber. PlanType exists only in the SL1 schema (StudentLoanStart-v2-3.xsd). A PGL1 file containing PlanType would fail HMRC's own schema, so the mapping can't expect it as a source field.

The DPS Inbound Mapping (rows 32 and 33) already covers this:
- PGL1: match $hr.national_id with <NINO> and update the loan start date in 58226 from <LoanStartDate>, with pay element value 1 by default.
- PGL2: same match, update the loan end date in 58226 from <LoanStopDate>.

Could you please align the PGL1 and PGL2 mapping for REF-01-911 with this?
