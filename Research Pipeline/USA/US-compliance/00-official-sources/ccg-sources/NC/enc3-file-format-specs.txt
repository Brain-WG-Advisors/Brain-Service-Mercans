eNC3 File Format Specifications
eNC3 File Format Specifications

To file using the Web File Upload option, your business must have internet access and the ability to create fixed field text files (.txt) containing NC-3 and W-2 information as well as eXtensible Markup Language files (.xml) 1099/W2-G/1042-S information using the required file specifications mandated by the IRS, SSA, and NCDOR. Creating TXT or XML files requires specific software or help from a software developer. Converting a PDF to a TXT will not generate a file in the correct layout. Click on the applicable tab below to find the NCDOR file specifications.
