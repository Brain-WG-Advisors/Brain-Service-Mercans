# CCG modules (cross-cutting guide)

The 13 modules of the United States Country Configuration Guide v1.0, plus the coverage table. Federal and per-State detail is in `10-federal.md` and `12-states/`.

- `01-ccg/coverage.md` - coverage.md
- `01-ccg/m01_foundational.md` - Module 1: Foundational Jurisdictional Parameters
- `01-ccg/m02_master_data.md` - Module 2: Master Data Configuration
- `01-ccg/m03_gross_to_net.md` - Module 3: The Gross-to-Net Calculation Framework
- `01-ccg/m04_compensation.md` - Module 4: Gross Compensation
- `01-ccg/m05_social_security.md` - Module 5: Social Security & Pension Systems
- `01-ccg/m06_tax.md` - Module 6: Income Tax Withholding System
- `01-ccg/m07_deductions.md` - Module 7: Deductions, Exemptions & Benefits
- `01-ccg/m08_leave.md` - Module 8: Statutory Leave Management
- `01-ccg/m09_termination.md` - Module 9: Termination & Irregular Payments
- `01-ccg/m10_reporting.md` - Module 10: Reporting, Compliance & Finalisation
- `01-ccg/m11_advanced.md` - Module 11: Advanced Scenarios & Cross-Cutting Logic
- `01-ccg/m12_worked_examples.md` - Module 12: Gross-to-Net Worked Examples
- `01-ccg/m13_practices.md` - Module 13: Common Business Practices & Non-Statutory Rules
