# Kazakhstan 2026 – official legal sources (payroll: ИПН, СН, ОПВ, ОПВР, СО, ВОСМС, ООСМС)

Scope: October 2026 payroll, Mastercard (run in 1C). Prepared 2026-10-14.
Publisher of every file below: **adilet.zan.kz** (ИПС «Әділет», Institute of Legislation and Legal Information under the Ministry of Justice of RK). All texts are the Russian-language consolidated versions.

**How the files were obtained.** adilet.zan.kz is now a JavaScript app. Its public JSON API serves the same document the web page renders, and that is what was saved:
- page URL (human): `https://adilet.zan.kz/rus/docs/<group_number>`
- content: `https://adilet.zan.kz/api/documents/<version-uuid>/content`
- metadata: `https://adilet.zan.kz/api/documents/<version-uuid>`
- version list: `https://adilet.zan.kz/api/documents/<version-uuid>/versions`

`raw/*.content.json` is the file exactly as downloaded with curl. `raw/*.meta.json` and `raw/*.versions.json` hold the metadata and version list. `text/*.html` is the `text_content` field pulled out of the JSON without changes, and `text/*.txt` is a plain-text rendering used for searching. In every case the version saved is the one flagged `is_current: true` on adilet as of 2026-10-14. adilet stores dates as UTC midnight−6h, so `2026-06-30T18:00Z` means 01.07.2026 local; the dates below are already converted to local.
