# raw

Material bruto, imutável. Não editar nem apagar.

| Pasta | Conteúdo | No git? |
|---|---|---|
| `chats/` | Extrações dos projetos do Claude | sim |
| `tickets/` | YouTrack (PDFs fora do git; texto em `txt-utf8/`) | sim (texto) |
| `docs/` | Documentos avulsos | sim |
| `reunioes/` | Transcrições de reunião (Meet/Gemini), via Claude in Chrome. Nome: `AAAA-MM-DD-<reuniao>.txt` | **não** |
| `drive/` | Arquivos do Drive "Compliance Team" (Version Control, changelogs, RCA), via Claude in Chrome. Estrutura: `drive/<Pais>/<arquivo>` | **não** |

`reunioes/` e `drive/` ficam só nesta máquina (.gitignore): podem ter dados de pessoas e de clientes.
