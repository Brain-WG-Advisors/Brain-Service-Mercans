Quarterly Wage Reporting File Testing

After the launch of MiUI, employers and third-party administrators (TPAs) must submit past due and current Quarterly Wage Reports in MiUI. It is recommended employers and TPAs test the wage report file formats prior to the system rollout following the information below.

Need help on using the Wage Report Validator Tool linked below? Refer to this guide for more information.

File Format Specifications

Prepare your test file according to one of these four file formats:

  • Delimited (CSV Comma Delimited)

    File extensions: .txt or .csv

  • ICESA (NASWA Standard File Format)

    File extension: .txt

  • EFW2 (Formerly MMREF-SSA)

    File extension: .txt

  • XML (Standard XML Format)

    File extension: .xml

The MiWAM file format will no longer be accepted.

Employers and/or Third-Party Administrators (TPAs) will need to update existing processes to reflect acceptable file formats.

 

 

Do not upload actual employer information or personally identifiable employee data during this testing process. This test process is not secure.

The Michigan Unemployment Insurance Agency will not be responsible for any data breaches or unauthorized disclosure resulting from use of this test system.
