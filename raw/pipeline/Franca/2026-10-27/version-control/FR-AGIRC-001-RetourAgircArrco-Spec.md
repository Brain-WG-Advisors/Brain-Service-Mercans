|  | Why this workbook specifies a field set it says you will rarely see | The spec sheet carries the full normalised NEOReS field set even though AGIRC-ARRCO uses it for one control today. And AGIRC-ARRCO's participation can only grow - the cahier technique's stated target is that every return requiring a payroll update joins the norm. What the workbook refuses to do is present that field set as though it described how AGIRC-ARRCO anomalies reach the employer today, which is why the finding appears on the Report Matrix banner and on the spec sheet's own header rather than in a footnote. |  |  |  |
