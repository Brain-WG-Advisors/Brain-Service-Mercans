Batch Contribution Process

The batch process allows you to submit files through a secure file transfer protocol and remit NACHA payments through your financial institution using ACH Credit.

  1. Home
  2. Remit Contributions
  3. Batch Contribution Process

You must create a ct.gov account and register your business before you can begin the batch contribution process.

﻿﻿

The Process

  1. Step 1

    Request SFTP server access

  2. Step 2

    Enroll your clients and remind them to register

  3. Step 3

    Prepare and upload return filings

  4. Step 4

    Remit NACHA payment

  5. Step 5

    Prepare and upload amended return filings (when changes are necessary)

  6. Step 6

    Remit additional contributions (when necessary)

Step-by-Step

Download the File Specification Toolkit and read it along with the step-by-step instructions for the best understanding of the process.

File Specification Toolkit (PDF)

  1. Request CT Paid Leave SFTP server access

    You must request access to the CT Paid Leave Authority’s Secure File Transfer Protocol (SFTP) server so that you are able to submit your enrollment files, return files and amended return files.
    SFTP ACCESS
    The SFTP server for submitting files to the CT Paid Leave Authority is a different SFTP server than the one used to upload files for other State of Connecticut taxes.

  2. Enroll your clients and remind them to register

    If you are an employer remitting your own contributions, you should skip this step.

    If you are a third-party administrator, enrolling your clients through the batch process allows you to remit contributions on their behalf. However, this does not mean their registration is complete. Your client employers must complete their own business registrations after being enrolled to provide additional business information and so that they have access to the business in the My Account for Business portal.

    To enroll your clients, you will need to upload an enrollment file to the Inbound folder on the SFTP site. Refer to the File Specification Toolkit (PDF) for detailed file specifications to create and name your enrollment files.

    After your enrollment file is processed, an acknowledgment file will appear in the Outbound folder. Check the acknowledgement file to see if the enrollment file processed successfully or if there are any errors to fix. Review the Acknowledgment Files section lower on this page for details on how to create a file with only your fixed records. Warnings do not need to be fixed with this submission but should be used to correct future files.

    Adding a New Client to Your Enrollment File

    The date you choose to enroll your client denotes the quarter in which your quarterly return filing for the employer should start. For example, if you enroll a new client in June, CT Paid Leave will anticipate a Q2 return filing for you on behalf of your client.

    Ending a Client Employer Relationship

    If you populate an end date to your relationship, it does not close an account in our system. If an employer will close or will permanently stop paying wages, it must notify the CT Paid Leave Authority immediately by submitting a Contact Us inquiry, choosing "Help with Business Registration/My Account for Business" as the contact reason.

    Enrollment File Submission Frequency

    Enrollment files must be submitted quarterly. If you take on a new client employer or end a client employer relationship in the middle of a quarter, submit an enrollment file at the time these changes occur rather than waiting until the end of the quarter. Your relationship start date should remain the same on your enrollment file, or you may potentially create duplicate enrollments between you and your clients.

    The quarterly enrollment files should be submitted before return files are submitted and contributions are remitted.

    Contributions are due on the last day of each quarter; however, penalties and interest will not be charged if contributions are submitted before the last day of the month following the end of the quarter.

    Remind Your Client Employers to Register but Not Remit

    Enrollment of your client employers is different from employer registration. Notify your client employers that they must complete their business registration through the CT Paid Leave portal. Ask them to follow the registration step-by-step instructions found on How to Register as an Employer.

    At the same time, notify your client employers that they should NOT make contributions to the CT Paid Leave Authority since you will be remitting on their behalf.

    It may take up to an hour for files to be picked up from the Inbound folder for processing and up to 48 hours to process depending on the size of the file.

  3. Prepare and upload return files to SFTP server

    The return file conveys information about the contributions that will be remitted either for your own business or on behalf of your client employers.

    CT Paid Leave accepts batch return files in two file formats: XML or CSV. Both file formats contain the same information. Refer to the File Specification Toolkit (PDF) for detailed file specifications to create and name your return files. After creating the files, you will need to upload them to the Inbound folder on the SFTP site.

    Return File Submission Frequency

    CT Paid Leave requests that return files are submitted quarterly. You may submit return files more frequently if you are also remitting contributions to match. Each return file must be attributed to a quarter and should not span multiple quarters.

    Review Acknowledgment Files

    After your return file is processed, an acknowledgement file will appear in the Outbound folder. Check the acknowledgement file to confirm that the return file processed successfully or see if there are any error to fix. Review the Acknowledgment Files section lower on this page for details on how to create a file with only your corrected records. Warnings do not need to be fixed, but you should use the information to correct future files.

    It may take up to an hour for files to be picked up from the Inbound folder for processing and up to 48 hours to process depending on the size of the file.

    Return file and contribution remitting process diagram (PDF)

  4. Remit contribution through financial institution

    Batch contributions are made by sending an ACH Credit NACHA file to your financial institution, who will then deliver the funds to CT Paid Leave's financial institution also following the NACHA format. Refer to the File Specification Toolkit (PDF) for detailed file specifications to create your NACHA payment file.

    The CT Paid Leave Authority requires you to include two addenda records to capture critical information used to attribute the contributions to the correct employers for the correct contribution periods.

    Prior to remitting your first contribution, follow the steps in the File Specification Toolkit to submit a penny test.

    Once you complete a successful penny test, you may remit contributions.

    It may take up to 5 business days before the payment clears with our bank and then completes posting to the My Account for Business portal. Check back periodically to view completed payments.

  5. Prepare and upload amended return filings (when changes are necessary)

    Amended returns can be filed via our batch process or our online portal process. Batch filers may amend batch returns using either the batch amended return process or online portal amended return process. To amend a return through the online portal process, the user must be either:

    • a related contact on the employer account in our system; or
    • a contact on the related TPA account who has a current established relationship with the employer account in our system.

    If you need to amend a previously submitted batch return file, view the guides below for instructions and specifications on how to submit amended return files.

    Guide to Amended Returns Filed through the Batch Process (PDF) Guide to Amended Returns Filed through the Online Portal Process (PDF)

    What changes can you make with an amended return?

    • Reported wages
    • Contribution amount
    • Employee counts

    What changes can you not make with an amended return?

    Any changes other than those listed as changes you can make must be submitted to the CT Paid Leave staff through a Contact Us inquiry. Such manual changes include but are not limited to the following:

    • Pay period start and end dates
    • TPA or Employer FEINs
    • Reporting quarter or reporting year
    • Any changes to a return your business did not submit

    Employer Contribution Refunds

    If a batch amended return results in an employer who overpaid on their contributions, they will see that they are owed a refund in the My Account for Business portal. Refunds are not automatically dispersed in case there are additional amendments.

    Employers should request a refund using the contact us form. Select "Employer Refund Request" as the contact reason when completing the contact form.

    After submitting your request for a refund through the contact us form, you can expect to receive a decision within 7 days. Once approved the refund is typically issued within 30 days.

    Employer contribution refunds are handled differently for amended returns filed through the online portal process.

  6. Remit additional contributions (when necessary)

    When amending returns result in underpayments, you can remit additional contributions through your financial institution following the same ACH Credit NACHA file format used for initial contributions.

Acknowledgment Files

The acknowledgment file documents the status of the submitted file after processing and communicates any processing errors encountered back to the submitter. The acknowledgment file will maintain count of accepted and rejected employers. Any errors associated with an employer will appear in an XML block for that employer. If no error is encountered for a given employer, no employer xml block will exist in the acknowledgment file.

Download Acknowledgment Files

Keep acknowledgment files as proof of your file submission. Files will only be available on the SFTP server for 60 days before they are automatically removed.

Warnings

If your file had warnings, it included mistakes or was incomplete but we were able to process the data.

Do not resubmit. Please use the information to correct your future files.

Errors

If your file had errors, we were unable to process the data. A copy of your original file will be uploaded to the outbound folder with the file extension .error appended to the file name.

You will need to correct the errors and resubmit the file.

Correcting errors

Create a new file with only the corrected records using these steps:

  1. Save a copy of the original file, increasing the two-character revision indicator in the name.
  2. Remove all successfully processed records, leaving only the records that were reported as having errors.
  3. Correct the errors.
  4. Upload the new file to the Inbound folder on the SFTP site.

The File Specification Toolkit (PDF) provides additional information on the acknowledgment file format, error codes and warning codes.

Non-Compliant Accounts

An account is not compliant when both wage reports and contributions are not submitted at all or are submitted after the last day of the month following the end of the calendar quarter. For example, Quarter 1 contributions will be considered to be compliant only if they are received no later than April 30th.

If an account is non-compliant, account contacts will receive a notice either by email or through the United States Postal Service. Always keep account contact information in My Account for Business current to ensure timely receipt of notices.

  1. Missing return and missing contribution

  2. Return received but missing payment or payment was late

  3. Payment received but missing return or return was late

  1. Non-compliant with missing return and missing contribution

    1. The employer will be sent communications through email or US postal mail stating that the reporting of contribution wages is missing. An email is sent to each valid email associated with the employer. If there are no valid email addresses, the notification is sent through US postal mail instead.
    2. The third-party administrator (TPA) or employer must upload a return file with wages for the quarter and a contribution NACHA payment of 0.5% of wages.
    3. The TPA or employer must submit a NACHA payment matching the contribution amount, payor FEIN and employer FEIN on the return file. Wages should contain wages for the quarter, the same as specified on the return.
    4. CT Paid Leave will calculate the penalty and interest owed based on the information provided in the return file. The total amount due will be the sum of the contribution amount, penalty and interest.
    5. The contribution received will be applied to the total amount due in the following order: Penalty, Interest, Contribution Amount.
    6. The TPA or employer must pay off the remaining balance either through the online portal or by making an additional NACHA payment. The total amount due is available from the online portal or most recent correspondence. When paying through the online portal, the payoff balance will be calculated in real-time for you.

  2. Non-compliant with return file received but no payment received or the payment was late

    1. The employer will be sent communications through email or US postal mail providing a breakdown of contributions, penalty, and interest owed. These amounts are calculated from the received return. An email is sent to each valid email associated with the employer. If there are no valid email addresses, the notification is sent through US postal mail instead.
    2. The third-party administrator (TPA) or employer must submit a NACHA payment for the total outstanding amount communicated on the email or letter.
    3. The contribution received will be applied to the total amount due in the following order: Penalty, Interest, Contribution Amount.
    4. If there is any remaining balance owed, CT Paid Leave will send another email or letter with the remaining balance owed and will provide a link and QR code to remit the payment using Paylink.
    5. The TPA or employer must pay the remaining amount owed through Paylink or through another NACHA payment.

  3. Non-compliant with payment received but no return file received or a late return file was received

    1. The employer will be sent communications through email or US postal mail stating that a contribution payment was received but return filing is outstanding for a particular year and quarter. An email is sent to each valid email associated with the employer. If there are no valid email addresses, the notification is sent through US postal mail instead.
    2. CT Paid Leave will assess a $50 penalty for filing a late return file.
    3. The third-party administrator (TPA) or employer must submit a return file with wages for the quarter.
    4. The TPA or employer must pay the $50 penalty either through the Paylink link or QR code in the communication received, or by remitting another NACHA payment. If remitting another NACHA payment, the wages on the NACHA file should match wages for the quarter, and the contribution should reflect the $50.00 penalty.

Frequently Asked Questions

Submit a Contact Us inquiry and select “SFTP Access” as the contact reason. In the body of your inquiry, specify "I lost my SFTP credentials" or "I need my password reset."

You must be an authorized account contact to receive SFTP credentials or have SFTP credentials reset. To confirm that you are an authorized account contact sign in and go to the My Account for Business portal by clicking on your name in the upper right corner of the screen and selecting My Account for Business from the drop-down menu. If the business that you are requesting SFTP information about is listed, you are an authorized account contact. If you do not see the business listed, you must have an existing account contact invite you to the account.

The CT Paid Leave Authority will issue a refund of the penny test back to the issuing bank account within thirty days.

Third-party administrators (TPAs) and employers filing with the batch process submit a quarterly return file. This file represents the CT Paid Family Leave contributions collected for the applicable time period. Follow the file layout specifications from our File Specifications Toolkit (PDF).
