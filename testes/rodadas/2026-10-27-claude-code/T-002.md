# T-002
**Question:** Spain, ES-AFI-001 (TrabajadoresTramos): what does TRL stand for and what does it represent?

**Answer:**
TRL = "Tipo de Relación Laboral" (type of labour relationship). It is a 3-digit code (000-999) in the InformacionAfiliacion block. The code identifies the worker's type of labour relationship, for example ordinary employment vs special/specific collectives. TRL 087 is one case: the TGSS SLD manual restricts certain hour fields to it.
- It is NOT a work-risk / AT-EP rate code. AT/EP comes from CNAE + Ocupación/Epígrafe.
- Our earlier answer "Work Risk Type" with a 000/500/800 scale was wrong.
- It is a read-only field returned by TGSS (no mapping required).
