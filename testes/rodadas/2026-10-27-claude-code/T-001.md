# T-001
**Question:** Spain, TGSS CRA report (ES-CRA-001): in the termination month, which Mercans wage types are reported for the end-of-contract amounts, with which CRA concept code and type (I/E)?

**Answer:**
Per the current spec (ES-CRA-001 v2.3, as settled in SR-81), the termination-month CRA records are:
- 58184 Severance Final Exempt Amount - Objective Dismissal → 0054 / E
- 58186 Severance Final Exempt Amount - Unfair Dismissal → 0054 / E
- 58188 Severance Final Taxable Excess → 0054 / E
- 62983 Non-Taxable Severance also carries CRA code 54 / E (WTC V4.7, HRBS-10563).

58197 / 58198 (prorated severance) are BASES-only (L03 proration, base 701) and do NOT go in the CRA. Our April 2026 answer "58197 0054/I + 58198 0054/E" was wrong.

Caveat (open, not resolved): the I/E flag for 58188 is in question. LGSS art. 147.2.c exempts severance only up to the mandatory amount, so the excess over it is contribution-subject (I, not E). WTC V4.7 has a related inconsistency: on 58188, BCCC/BCCP = "No", but its explanation text says SS-subject = Yes. This is a design decision for the Support/Design front. Nothing changes until that decision is made.
