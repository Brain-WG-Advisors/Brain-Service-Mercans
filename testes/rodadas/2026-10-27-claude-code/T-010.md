# T-010
**Question:** Ukraine, 4DF: payments to a civil contractor registered as FOP who provides the supporting documents: which income code and Mercans WT, and are PIT, Military levy and ESV due?

**Answer:**
- Income code: 4DF **157** (income paid to a self-employed person / FOP).
- Mercans WT: **62942** "Payment to Individual Entrepreneur (Documented Registration)".
- **PIT = No, Military levy = No, ESV = No.** Under PKU p. 177.8, the payer does not withhold PIT when the FOP provides the document confirming state registration. The 4DF tax columns are filled with zeros. The FOP pays its own taxes and ESV.

Defect found: 4DF spec v3.3 (Drive), sheet Option Mappers B72, labels code 157 as "Дохід нерезидента (загальний) / Non-resident income — general". That is wrong and should be fixed. Spec "Gross Income" E339 maps 62942 → 157 correctly.
