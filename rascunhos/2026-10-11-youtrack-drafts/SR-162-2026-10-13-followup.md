1. Row 49 (LINKED_DOCS) is not blank: D5 is an appendix to the Tax Calculation J05 001 (section 06, row 065), so LINKED_DOCS references the main document (one DOC, TYPE="2").
Row 51 (SOFTWARE) may be empty and is written as `<SOFTWARE xsi:nil="true"/>`. xsi:nil="true" is required whenever an element is sent with an empty value; in the header, only LINKED_DOCS and SOFTWARE may be empty.

2. Added to DD V4.1, Country Fields rows 83–85. Region Code is not Oblast (Region): it is the region code of the ДПС office the report is submitted to (ДПС directory SPR_STI, e.g. 26 = Kyiv city).

Source: Наказ Міндоходів № 729/2013, Додаток 1; form J05 001, section 06.
