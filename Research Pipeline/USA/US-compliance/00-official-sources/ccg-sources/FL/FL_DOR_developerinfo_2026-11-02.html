Software Developer Information and Specifications

Software Developer Information and Specifications

Specifications are provided for developers creating software to electronically file tax returns. This information is for:

  • Commercial software vendors developing tax filing applications.
  • Organizations creating in-house software solutions for direct electronic filing of their tax returns.

All software developers must complete a Software Development Application (Form DR-600001 ).

For additional information regarding developing filing software, contact the EDI/XML Development Team at e-vendor@floridarevenue.com.

  • Communications Services Tax Direct File Specifications - Includes record layouts and field requirements for flat file format.

  • Corporate Income Tax Modernized e-File specifications are available on the Federation of Tax Administrators (FTA) State Exchange System (SES).

  • Insurance Premium Tax XML Package (Zip archive) - Includes XML schema, XPath, guide, and test files.

  • Motor Fuel Taxes XML Package (Zip archive) - Includes XML schema, XPath, guide, and test files.

  • Reemployment Tax Data Exchange (Password protected ZIP archive) - Data exchange formats for providers with memorandum of understanding (MOU) agreements.
  • Reemployment Tax XML Package (ZIP archive) - Includes XML schema, XPath, guide, and test files for Forms RT-6 and RT-8A.

  • Sales and Use Tax, Solid Waste Surcharge and/or Prepaid Wireless Fee XML Package (Zip archive) - Includes XML schema, XPath, guide, and test files.
