## Payroll Scope Summary

| US-LOC-001 LOCAL INCOME / WAGE TAX RETURNS — PAYROLL SCOPE SUMMARY |  |  |
|---|---|---|
| Separate locality returns in the 11 jurisdictions with local returns (New Jersey local employer taxes are in US-LOC-002). |  |  |
| SCENARIO | REPORT? | NOTES / REASONING |
| ═══ WHO GETS REPORTED ═══ |  |  |
| Employees working or living in a locality with its own return | YES | State sections. |
| Indiana county, Maryland county, NYC / Yonkers | NO | Reported on the State return (US-DOR-001 row DOR-C-008). |
| ═══ TIMING & RELATIONSHIP ═══ |  |  |
| Periodic returns and annual reconciliation per locality | YES | State sections. |
| ═══ AMOUNTS & CALCULATIONS ═══ |  |  |
| Flat amounts and percentage taxes | YES | See Example Analysis. |
| ═══ SPECIAL CASES ═══ |  |  |
| Nonresident alien employees | PARTIAL | Reported like other employees unless the jurisdiction rule in its section says otherwise; federal treaty exemptions do not change State reporting by themselves. |
| Household and agricultural employees (State level) | NO | State-level rules for special populations are deferred to a later round [US-OWN-005]. |
| Independent contractors | NO | Out of scope [US-OWN-008]. |
