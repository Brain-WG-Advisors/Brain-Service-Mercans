Vermont Electronic W-2 (EFW-2) Filing Specifications

Printer-friendly PDF

This guidance is provided for those who file W-2 Forms using myVTax. 

Who Must File Electronically

Filing using myVTax is required for:

  • Taxpayers filing more than ten total combined number of W-2 and 1099 forms. 
  • Payroll filing services and tax preparers submitting informational returns for multiple employers

Bulk Upload Formatted EFW-2 Files

Payroll services and tax preparers submitting for multiple companies can upload bulk files of formatted W-2s.

Data Entry of Form EFW-2s

Employers submitting for their employees have the option to data-enter W-2 forms.

Vermont follows the Social Security Administration (SSA) guidelines for electronically filing Form W-2. The following information provides a brief overview of specifications for those employers and tax preparers who are required to submit W-2 statements electronically. For more information and file layouts, see SSA’s Publication 42-007, "Specifications for Filing Forms W-2 Electronically (EFW-2)" for the tax year.

Record Format and Record Layout Specifications

The Vermont Department of Taxes requires employers to use the same format to file W-2s containing Vermont withholding tax. All information must be submitted as required by appropriate federal guidelines and modified for Vermont using the guidelines on this page.
