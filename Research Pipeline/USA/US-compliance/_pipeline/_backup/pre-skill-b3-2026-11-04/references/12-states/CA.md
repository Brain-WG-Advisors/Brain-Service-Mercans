# Annex CA: California


This annex sets out the California payroll rules for the 2026 build year. Read with the federal reference (the federal layer every employee carries) and the multistate reference (which routes an employee to this State by work location, residence or UI localization). Every value is shown with its effective dates and its source (list at the end of the annex). Federal values are not repeated here.

Classification: T3. Separate State withholding (PIT) and payroll taxes (UI, ETT, SDI) on one EDD return set; no local wage tax; local minimum wages exist.

## CA.1 Employment and labour code

State minimum wage USD 16.90 for 2026 and USD 17.40 for 2027. Overtime: 1.5x over 8 h/day, over 40 h/week and first 8 h of 7th consecutive day; 2x over 12 h/day and over 8 h on 7th day (Lab. Code 510); alternative workweek exceptions. No tip credit. Cities and counties may set higher minimum wages and some industries have their own minimums: both are blocking gaps below, so a California work location cannot be paid at the State rate without first checking the locality and the industry.

## CA.2 Income tax withholding

**Method.** Method A (wage-bracket tables, wages < 1M) or Method B (exact calculation), DE 44 Rev. 52 (4-26). Certificate: DE 4 Rev. 56 (1-26); federal W-4 for FIT only since 2020; no valid DE 4 = Single 0 allowances; exempt status renewed by Feb 15. Method B, per pay period:

```
annual_wages = period_wages x pay_periods
if annual_wages <= low_income_exemption(status, allowances): tax = 0
taxable      = annual_wages - estimated_deduction x additional_allowances - std_deduction(status, allowances)
annual_tax   = brackets(status)(taxable) - allowance_credit x allowances
period_tax   = max(0, annual_tax) / pay_periods
```

**Which table applies to which DE 4 status.** DE 4 filing status -> DE 44 Method B table: 'Single or Married (with two or more incomes)' -> Table 5 'Single Persons, Dual Income Married or Married with Multiple Employers'; 'Married (one income)' -> Table 6 'Married Persons'; 'Head of Household' -> Table 7 'Unmarried/Head of Household' (annual payroll period; the same three-way order repeats for every payroll period in Tables 8-28). Table 1 (low income exemption) and Table 3 (standard deduction): 'Single or Married (with two or more incomes)' -> column 'Single, Dual Income Married or Married with Multiple Employers'; 'Married (one income)' -> column 'Married' for '0' or '1' allowances, or column 'Married' for '2' or more allowances (allowances on DE 4 or Form W-4); 'Head of Household' -> column 'Unmarried Head of Household'. No DE 4 on file -> Single with zero allowances.

Bands by status: the single band table in this section is DE 44 (2026) Method B Table 5 (annual), the married band table is Table 6 (Married, one income) and the head-of-household band table is Table 7; each gives the rate, the ceiling and the tax at the bottom of each band (base). A married employee who checks 'Single or Married (with two or more incomes)' is withheld on the single table, never on the married table. The same status mapping selects the column of the low-income exemption and standard deduction tables. Married ceilings: 22,158 / 52,528 / 82,904 / 115,084 / 145,448 / 742,958 / 891,542 / 1,000,000 / 1,485,906; 14.63% over; base 164,228.58; head of household ceilings: 22,173 / 52,530 / 67,716 / 83,805 / 98,990 / 505,208 / 606,251 / 1,000,000 / 1,010,417; base 107,334.77.

**Supplemental pay** paid separately: bonuses and stock options 10.23 %; other supplemental pay (overtime, commissions, severance, vacation pay) 6.6 %. Household employees: withholding only by agreement.

California does not conform to the federal P.L. 119-21 deductions and taxes employer HSA contributions; see CA.8.

## CA.2b Non-resident regime and reciprocity

Sourcing: residents: all wages with credit for other-state withholding (withhold excess only); nonresidents wholly in CA: all wages; split-state: CA working days / total working days (volume ratio for commissions); military spouse exclusion on DE 4.

|---|---|---|

| Annual bonus / supplemental pay | 10.23 % (bonus) or aggregate | Same, on the California portion |
| Severance | 6.6 % when paid separately, or aggregate | Same, on the California portion |
| Equity (stock options) | 10.23 % when paid separately, or aggregate | Same, on the California portion |

| Contractor pay | Independent contractors and Form 1099-NEC reporting are out of scope (owner instruction of 2026-10-29) [US-OWN-008] | Same |

## CA.15 Special populations

- Domestic and household workers: UI and ETT above the quarterly cash-wage threshold; SDI above its own quarterly threshold; PIT only by agreement; the Lab. Code 226 statement does not apply.
- Agricultural workers: UI, ETT and SDI apply; PIT withholding not required but PIT wages reportable (H-2A the same); overtime phase-in open (CA.1).
- Minors: learner rate (85 % of minimum wage, any age); newspaper carriers under 18 excluded from UI, SDI and PIT.
- Tipped employees: no tip credit.
- Clergy: ministers and religious orders not subject to UI and SDI (elective) and PIT withholding not required; church employees not subject to UI and SDI, subject to PIT.
- Students: own-school students, student nurses, young work-study students and organised-camp students not subject to UI and SDI, subject to PIT.
- Non-resident aliens on F, J, M or Q visas: excluded from UI and SDI (CUIC 608); PIT subject unless a treaty covers State taxes.
- Statutory employees: UI and SDI per DE 231TE/SE; commissioned authors no PIT withholding.
- Government: UI subject; SDI only by election; PIT subject; elected officials, judiciary and National Guard not subject to UI and SDI.

Not configured in this release (open gap RQ-514): The coverage thresholds that apply to these populations (quarterly cash-wage and headcount thresholds for UI coverage of domestic, agricultural and non-profit employment) are cited by statute only and are not established as values; the engine must not hard-code them until they are established.
