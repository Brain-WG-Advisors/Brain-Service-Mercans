## Resposta

**C_REG**: the 2-digit region code of the territorial DPS body that receives the document. It is filled from the directory of territorial bodies (SPR_STI.XML) and corresponds to that body's C_REG value.

**C_RAJ**: the district code of that same receiving body, also taken from SPR_STI.XML, matching the body's C_RAJ value.

**C_STI_ORIG**: the code of the body that receives the original document, a numeric value from the directory equal to C_REG × 100 + C_RAJ.

These values are not fixed. They depend on which DPS body each legal entity files with, so they are set per entity. For example, ГУ ДПС у м. Києві is 26 / 50 / 2650, and the Central Interregional Office for Large Taxpayers is 31 / 0 / 3100 (SPR_STI.XML, 06.03.2026). They are DPS directory codes, not KATOTTH codes and not the employee's oblast. Because D1 (J0510111) is filed in the same J05 package to the same body, its values are the same as in the main J0500111.

The same codes also appear in the file name. Positions 1–4 are C_REG and C_RAJ, each left-padded with a zero to 2 characters, and positions 40–43 are C_STI_ORIG, left-padded with zeros to 4 characters.

Source: Order of the Ministry of Revenues and Duties No. 729, Annex 1, DECLARHEAD table (zakon.rada.gov.ua, z0243-14), together with the DPS directory SPR_STI.XML.
