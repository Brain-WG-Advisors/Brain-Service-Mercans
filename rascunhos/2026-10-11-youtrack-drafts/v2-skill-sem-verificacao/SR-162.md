**Rows 55–56 (HDDGV / HNDGV):** not required. Both are optional and nillable in the XSD (`minOccurs="0"`, `nillable="true"`); HDDGV is a DDMMYYYY date (length 8), HNDGV free text with no length limit. An empty tag is not valid — the element is either absent or `xsi:nil="true"`.

**Rows 37–51:** "Blank" is correct only for row 49 (LINKED_DOCS) and row 51 (SOFTWARE), both `minOccurs="0"`. In the XSD:
- Row 43 C_REG and row 44 C_RAJ are mandatory, integer 0–99 (type DGsti) — region and district code of the ДПС office where the payer is registered.
- Row 48 C_STI_ORIG is mandatory, code of the ДПС office (type DGc_dpi, 3–4 digits).
- Row 50 D_FILL is mandatory, type DGDate: DDMMYYYY, length 8, no separators.
- Rows 37–42 and 45–47 match the XSD as mapped (C_DOC J05, C_DOC_SUB 105, C_DOC_VER 10 fixed).

Source: ДПС XSD J0510510 (Додаток 5, C_DOC_VER 10, наказ Мінфіну № 39 of 24.01.2025 as amended by № 53), DECLARHEAD; types in common_types.xsd of the same package.
