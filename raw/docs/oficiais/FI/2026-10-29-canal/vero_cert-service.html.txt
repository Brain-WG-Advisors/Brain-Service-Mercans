The Tax Administration’s certificate service
The Tax Administration’s certificate service is an e-service in which you can manage your organisation’s API rights and certificates. The service is intended for businesses and organisations.
Use the certificate service to retrieve production and testing certificates for the following:
the Tax Administration’s APIs;
the Incomes Register’s APIs; and
the Positive credit register’s APIs.
            Production certificates
Submit an API application and request a production certificate.
Log in: Production certificates
Identify yourself to the certificate service. Check 
when you also need a Suomi.fi authorisation
.
Read the instructions for production certificates
            Testing certificates
Submit an API application for testing and request a testing certificate.
Log in: Testing certificates
Identify yourself to the certificate service. You do not need a Suomi.fi authorisation.
Read the instructions for testing certificates
Certificate for API Services
You need a certificate if you want to submit or retrieve data through APIs. For example, you can request data about an employee’s tax rate, submit your employees’ earnings payment data directly from your payroll software to the Incomes Register, or – if you are a lender – report loan contract data to the Positive credit register.
Certificates are used to identify and authorise organisations that submit data or retrieve data through APIs. They are also used to verify the integrity of records. The solution is based on digital certificates (Public Key Infrastructure).
A certificate is valid for two years, after which 
it must be renewed
. You can check the validity of a certificate on the certificate or by logging in to the certificate service. The new service will not affect the existing and currently valid certificates. All existing certificates remain functional throughout their validity period.
The use of APIs and certificates requires technical skills. Discuss with your software supplier the procedures related to using APIs.
