## Payroll Scope Summary

| US-PFML-001 STATE PFML / SDI / LTC PROGRAMME REPORTS — PAYROLL SCOPE SUMMARY |  |  |
|---|---|---|
| Programme reports filed separately from the State wage return. |  |  |
| SCENARIO | REPORT? | NOTES / REASONING |
| ═══ WHO GETS REPORTED ═══ |  |  |
| Employees covered by a State programme | YES | WA family and medical leave coverage follows the UI localization test; key premium state to sui_state unless a state unit proves otherwise |
| ═══ TIMING & RELATIONSHIP ═══ |  |  |
| Separate programme report | YES | Programme sections. |
| Programmes on another return | NO | CA SDI on DE 9 / DE 9C; OR Paid Leave on Form OQ; NJ TDI / FLI on NJ-927 / WR-30; RI TDI on TX-17 (US-UI-001, US-DOR-001). |
| Insurer-funded programmes without State report (NY DBL / PFL, HI TDI) | NO | False |
| ═══ AMOUNTS & CALCULATIONS ═══ |  |  |
| Premiums per programme rates | YES | CCG Module 5. |
| ═══ SPECIAL CASES ═══ |  |  |
| Nonresident alien employees | PARTIAL | Reported like other employees unless the jurisdiction rule in its section says otherwise; federal treaty exemptions do not change State reporting by themselves. |
| Household and agricultural employees (State level) | NO | State-level rules for special populations are deferred to a later round [US-OWN-005]. |
| Independent contractors | NO | Out of scope [US-OWN-008]. |
| Maryland FAMLI | NO | No contribution in 2026: FAMLI contributions from 2027-01-01. |
