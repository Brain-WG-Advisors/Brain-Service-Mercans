# T-012

**Pergunta:** Ukraine: which form code and version of Annex D6 of the Unified Report (J05 package) is in force for 2026 reporting periods, and since when?

**Resposta:**
D6 = **J0510611** (C_DOC J05, C_DOC_SUB 106, C_DOC_VER 11). It was approved by MinFin Order No. 4 of 13.01.2015, as amended by Order No. 243 of 07.05.2026 (together with Order No. 284 of 26.05.2026).

- **Since when:** in force from **17 July 2026**. Tax agents apply it from 1 August 2026, for reports covering July 2026 onwards.
- **Previous version:** version 10 (J0510610) has D_END 30.06.2026 in SPR_VER.
- **For 2026 periods:** January–June 2026 use v10 (J0510610); July 2026 onwards uses v11 (J0510611).
- **XML:** the file must reference J0510611.xsd. The generated D6 sample still pointed to J0510610.xsd while carrying C_DOC_VER 11; this was flagged in SR-163.

**Fontes:**
- SPR_VER.ZIP (tax.gov.ua, Last-Modified 06.10.2026): J05 sub 106, v10 with D_END 30062026; v11 with empty D_END, "наказ № 4 … у редакції наказу № 243". See `raw/docs/oficiais/UA/2026-10-15-VERIFICACAO-J05-v11.md` §2 (l. 27–30).
- DPS news of 14.07.2026 (tax.gov.ua/nove-pro-podatki--novini-/1031674.html): forms in force from 17.07.2026, applied from 1 August for July 2026. See the same file §3 (l. 32–36) and its Conclusion.
- Official package `raw/docs/oficiais/UA/j0500111-extraido/` (J0510611.xsd).
- paises/Ucrania.md l. 100, 201; correcoes.md (2026-10-01, SR-163: sample validated against superseded v10).
