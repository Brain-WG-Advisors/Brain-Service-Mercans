LINKED_DOCS (row 49) is not blank: D5 is an integral part of the Tax Calculation J05 001 (form section 06, row 065), and an appendix's LINKED_DOCS references the main document with one DOC, TYPE="2" (C_DOC, C_DOC_SUB, C_DOC_VER, C_DOC_TYPE, C_DOC_CNT, C_DOC_STAN and FILENAME of the main document).
SOFTWARE (row 51) may be empty. An element with an empty value is written with xsi:nil="true" (mandatory attribute), e.g. `<SOFTWARE xsi:nil="true"/>`; LINKED_DOCS and SOFTWARE are the only header elements that may be empty.

2. Added to DD V4.2, Country Fields rows 83–85 (light blue). Region Code is not the Oblast (Region) field: it is the region code of the ДПС office the report is submitted to, from the ДПС directory SPR_STI.XML (e.g. 26 = Kyiv city).

Source: Наказ Міндоходів № 729/2013, Додаток 1 (DECLARHEAD table and general rules); Tax Calculation form J05 001 (наказ Мінфіну № 4/2015), section 06, row 065 (same in versions 10 and 11); ДПС XSD J0510510/J0510511.
