## Payroll Scope Summary

| US-IRS-004 FORM 940 EMPLOYER'S ANNUAL FEDERAL UNEMPLOYMENT (FUTA) TAX RETURN — PAYROLL SCOPE SUMMARY |  |  |
|---|---|---|
| Employer-only federal unemployment tax on the first FUTA wages of each employee. |  |  |
| SCENARIO | REPORT? | NOTES / REASONING |
| ═══ WHO GETS REPORTED ═══ |  |  |
| Employees of a FUTA-liable employer | YES | FUTA base per employee. |
| Nonresident aliens in F, J, M, Q status | NO | True |
| ═══ TIMING & RELATIONSHIP ═══ |  |  |
| Annual return with quarterly deposits | YES | TY2025 rule: Form 940 for 2025 due February 2, 2026 (February 10, 2026 if all FUTA tax was deposited when due) (TY2025 rule, re-verify on the 2026 instructions) |
| ═══ AMOUNTS & CALCULATIONS ═══ |  |  |
| Annual wage base per employee | YES | 7,000 |
| Employee deduction | NO | FUTA is employer-only [US-FED-007]. |
| ═══ SPECIAL CASES ═══ |  |  |
| Household employers | NO | Schedule H (US-IRS-005). |
| Multistate employers | YES | One federal return; State credit per State of UI coverage; Schedule A (F940-009). |
| Wages paid in a credit-reduction State | YES | Schedule A; 2025 final list 2025 (final): CA 0.012 (1.2%); VI 0.045 (4.5%); no other state; 2026 list not final (open gap RSPEC-RQ-08). |
