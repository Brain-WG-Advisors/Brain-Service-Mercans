|  | LANGUAGE OF COLUMN B — POSITION AND OUTSTANDING DELIVERABLE | CCG Module 1.1 does **not** document a single national default language. It imposes the language of a personnel document by the region of the employer's seat of operation — Dutch in Flanders, French in Wallonia, German in Ostbelgien, the employee's language in Brussels — and states that bilingual personnel documents are not permitted in Belgium. Column B carries a Dutch rendering of the field name. Because no official field identifier or label is published for this declaration, the Dutch in column B is NOT an official label — it is a translation of the derived English name and carries no more authority than column A. |  | WHY THIS SPECIFICATION EXISTS AT ALL, GIVEN THAT NOTHING IS SOURCED | Limosa is a genuine statutory filing with a statutory deadline — before the posted worker starts — and BE-SIR-001 registers it as OUT-08. Omitting it would leave a real obligation with no specification and no visible gap. What this document does is state the obligation, state what the declaration must carry as far as the CCG and the SIR establish it, and mark every identifier, length, type, path and code table as DERIVED or NOT FOUND. A developer reading it learns exactly what to build and exactly what must be obtained from the NSSO before building it. That is the intended outcome; a plausible-looking XML layout would not be. |  |  |  |
|  | WEB-ONLY IS ITSELF THE FINDING | BE-SIR-001 Section 2.2 records the format for OUT-08 as 'Web declaration on the Limosa portal, returning the Limosa-1 receipt'. CCG Module 10.1 records the format simply as 'Web'. A technical channel does exist — BE-SIR-001 Section 3.3 records that it authenticates with a GlobalSign certificate and a technical user — but the SIR flags the source for that statement as the Working in Belgium portal, which is 'government-operated but is a guidance page rather than a technical specification', treated as confirmed for planning and to be re-verified at implementation. No message layout accompanies it. For a high-volume posting client, a web-only declaration is an operational constraint that must be raised in the implementation contract. |  |  |  |
