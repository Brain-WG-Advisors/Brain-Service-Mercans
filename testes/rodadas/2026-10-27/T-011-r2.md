For the Unified Report (J0510110 with annex D1), the three header fields identify the DPS body at the employer's main place of tax registration, and they must agree with each other.

**C_REG.** This is the region (oblast) code of the receiving tax office, taken from the DPS tax-office directory (SPR_STI.XML). It is the code of the region where the tax office receiving the document (original or copy) is located, filled in according to SPR_STI.XML.

**C_RAJ.** This is the district code of the same receiving tax office, also filled in from SPR_STI.XML. In the XML it is written as a plain number with no leading zero. The standard's own example uses C_REG 23, C_RAJ 1 and C_STI_ORIG 2301. The zero-padding to 2 digits applies only to the file name.

**C_STI_ORIG.** This is the code of the tax office receiving the original. It is taken from the directory and must equal C_REG × 100 + C_RAJ. For an original filing, positions 40–43 of the file name will match positions 1–4, so the two codes are the same office.

**Which office.** The Unified Report goes to the tax authority at the main place of registration (Law No. 2464, art. 6(2)(4), and Order No. 4, Section II, item 3). Annex D1 is part of the same package, so it carries the same C_REG, C_RAJ and C_STI_ORIG as the main J0510110 form.

**Current codes.** Since 01.01.2025, DPS changed the office or office code serving taxpayers, following its restructuring in line with the new administrative-territorial structure. Codes from before 2025 may therefore be out of date. In Kyiv, for example, the codes are now 2651 for Livoberezhna, 2657 for Pravoberezhna and 2650 for Tsentralna DPI. For Tsentralna that means C_REG = 26, C_RAJ = 50 and C_STI_ORIG = 2650. The office where a given employer is registered is shown in the private part of the taxpayer's Electronic Cabinet.

**Source.** These rules come from the Format (standard) of the electronic reporting document, approved by Order of the Ministry of Revenues and Duties No. 729 of 29.11.2013, in force from 21.03.2014. See Table 1 (DECLARHEAD elements) and the file-naming rules.
