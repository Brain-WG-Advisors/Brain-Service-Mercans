## Resposta

All three fields identify the **DPS territorial body that receives the original report**. They come from the DPS directory of territorial bodies (SPR_STI.XML), not from the employer's own address.

**Governing source:** Format (Standard) of the Electronic Reporting Document, approved by Order of the Ministry of Revenues and Duties No. 729 of 29.11.2013 (registered with the Ministry of Justice as z0243-14). The field rules are in Table 1 of para. 7 (DECLARHEAD), and the file-naming rules are in para. 4.

| Field | Rule (Order 729, Table 1) |
|---|---|
| **C_REG** | The code of the oblast where the receiving territorial body is located. It is filled in according to the directory of territorial bodies (SPR_STI.XML) and matches that directory's C_REG element. |
| **C_RAJ** | The code of the administrative district where the receiving territorial body is located, filled in from SPR_STI.XML. |
| **C_STI_ORIG** | The code of the receiving territorial body to which the original is submitted, taken from the same directory. It is a numeric value equal to C_REG*100 + C_RAJ. |

**How to populate them:**

- **Which body to use.** Use the DPI of the employer's main place of tax registration. It is shown in the Electronic Cabinet, both in the open section under "Дані про взяття на облік платників податку" and in the private section under "Реєстраційні дані" in the "Облікові дані платника" menu.
- **Split the 4-digit DPI code.** For example, Kyiv's 2650 Центральна ДПІ (Голосіївський р-н) gives C_REG=26, C_RAJ=50, C_STI_ORIG=2650. A 3-digit code such as 228 Вінницька ДПІ gives C_REG=2, C_RAJ=28, C_STI_ORIG=228.
- **Zero-padding applies only to the file name, not to the XML values.** Positions 1–4 of the file name hold C_REG and C_RAJ, each left-padded with zero to 2 characters. Positions 40–43 hold C_STI_ORIG, left-padded with zeros to 4 characters. If the document is an original rather than a copy, positions 40–43 match positions 1–4. For a J05 submission, C_STI_ORIG therefore always equals C_REG*100 + C_RAJ.
- **Annex D1 (J0510…).** Its DECLARHEAD should carry the same three values as the main J05 document, because the package goes to one recipient body.
- **Use current codes.** Because the DPS restructured its bodies in the oblasts and Kyiv to match the administrative-territorial system, the DPI or DPI service code changed from 01.01.2025. Codes from before 2025 may now fail validation.

**Sources:**
- Order 729 (full text): https://zakon.cc/law/document/read/z0243-14. The official version at zakon.rada.gov.ua/go/z0243-14 blocks automated access but is the same act.
- DPS list of current DPI codes from 01.01.2025: https://tax.gov.ua/data/files/501877.xlsx
