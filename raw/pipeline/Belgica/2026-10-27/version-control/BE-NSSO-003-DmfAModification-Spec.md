|  | NO NEGATIVE-DIFFERENCE DECLARATIONS | The single most consequential rule in this document: a correction is a RESTATEMENT of the original quarter, not a difference posted into the current one. Payroll engines that carry corrections forward as negative adjustments in the period of discovery cannot produce this declaration. CCG Module 10.5 puts it as a system requirement: the engine must be able to re-run the affected quarter end to end rather than patching a single figure. |  |  |  |
